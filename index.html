Geotab AVL Fleet Integration Standby / Simulator

Connect your SPPD escort cruiser or city vehicle equipped with Geotab GO hardware. The map polls DeviceStatusInfo every 5 seconds for real-time latitude, longitude, bearing, and speed.

Accepts JSON with { latitude, longitude, speed, bearing, status } or raw Geotab DeviceStatusInfo result array.

Geotab Read-Only Proxy Script (20 Lines)

Deploy this tiny serverless worker so your MyGeotab password stays private while feeding the public map: 

// Geotab Get<DeviceStatusInfo> Public Map Proxy
export default {
  async fetch(req, env) {
    const res = await fetch(`https://${env.GEOTAB_SERVER}/apiv1`, {
      method: "POST",
      body: JSON.stringify({
        method: "Get",
        params: {
          typeName: "DeviceStatusInfo",
          search: { deviceSearch: { id: env.SPPD_DEVICE_ID } },
          credentials: {
            database: env.GEOTAB_DB,
            userName: env.GEOTAB_USER,
            sessionId: env.GEOTAB_SESSION
          }
        }
      })
    });
    const { result } = await res.json();
    const d = result[0] || {};
    return new Response(JSON.stringify({
      latitude: d.latitude,
      longitude: d.longitude,
      speed: Math.round((d.speed || 0) * 0.621371), // km/h to MPH
      bearing: d.bearing || 0,
      isDriving: d.isDriving,
      updatedAt: d.dateTime
    }), { headers: { "Access-Control-Allow-Origin": "*", "Content-Type": "application/json" }});
  }
};
